# DESIIDE — Experience & Visual Design Brief

> **The feeling, in one line (added by the user, 2026-11-26):** Desiide is a new-gen editor. It must be **playful and psychologically relaxing**. Developers should *enjoy* coding here, the way you enjoy your own space after hours, not feel like they're clocking in to a job. Every screen fits the mood and vibe of devs; "functional but boring" fails review.
>
> In the IDE that means: calm, low-glare midnight surfaces; soft shapes; small rewarding moments (a satisfying lime check when a diff lands, one gentle pulse when a decision arrives); friendly empty states and copy with personality; ambient Afterhours touches that are opt-in; and nothing anxiety-inducing (no red walls, no alarm-style prompts, "needs you" is amber and kind). Delight lives in the moments between focus, never on top of the code.

## Creative Direction: Midnight Maker Culture

**Design philosophy:** Serious engineering. Playful culture. A little nerdy. A little futuristic. Never boring.

Desiide is being built for a new generation of developers, indie hackers, creators and technical founders. The experience should feel like a modern creative coding studio — somewhere between a late-night hacker workspace, a music-inspired creative environment and a next-generation developer tool.

Do NOT make Desiide look like traditional enterprise software, an outdated IDE, a generic SaaS dashboard or a stereotypical green-on-black hacker terminal.

### 1. Visual Identity

- Dark-first visual experience.
- Use deep charcoal, midnight navy and slightly tinted dark surfaces rather than pure black everywhere.
- Use electric lime as a distinctive brand accent, supported by restrained violet, cyan and occasional warm amber.
- Combine expressive modern sans-serif typography with monospace typography for technical details.
- Use subtle gradients, ambient glows, grain, grid patterns and layered depth.
- Create a recognisable visual identity without making every element glow.

The overall mood should be futuristic, expressive, atmospheric and comfortable for extended coding sessions.

### 2. Landing Page

The landing page should feel like entering a creative developer space, not reading a corporate product brochure.

- Strong, oversized hero typography.
- A visually engaging, real Desiide interface preview.
- Subtle motion and interactive elements.
- Sections should feel editorial and carefully composed, not repetitive rows of generic feature cards.
- Use screenshots, terminal snippets, code animations and real product demonstrations.
- Introduce the product's core philosophy: bring your own models, inspect AI decisions and review changes before they happen.
- Balance visual personality with clear product explanations and a visible GitHub / waitlist action.

### 3. Signature Experience: The Afterhours Corner

Create one small but memorable section on the landing page called **Afterhours** or **The Developer Lounge**.

This is inspired by the atmosphere-driven experience of ambient radio and illustrated virtual spaces.

Visitors should be able to explore a few developer-inspired environments:

- Rainy-night coding desk.
- Retro arcade / synthwave room.
- Midnight terminal café.

Each environment can have its own illustration, ambient visual treatment and optional background soundscape.

The section should feel like a little easter egg for developers and indie hackers — somewhere visitors remember after leaving the website.

Keep it compact. It is a brand experience, not the main product or a separate music application. Audio must be off by default, started explicitly by the visitor, and use original, licensed or properly authorised sound.

### 4. Actual Desiide IDE

The IDE must share the same identity, but prioritise concentration and usability over decoration.

- A polished dark-first editor experience.
- Refined sidebars, tabs, panels and workspace surfaces.
- Clear, distinctive states for AI thinking, model routing, tool execution, approvals and decisions.
- Subtle transitions, meaningful status indicators and carefully designed interaction feedback.
- Syntax highlighting and text contrast must remain excellent.
- Make technical information feel visually interesting without sacrificing readability.

The interface should feel like a next-generation developer studio, not a reskinned VS Code clone.

### 5. Motion & Interaction

Use motion to give the interface personality:

- Soft ambient transitions.
- Subtle cursor and terminal animations.
- Smooth task-stream updates.
- Visual feedback when an AI decision is made.
- Small interaction details that reward exploration.

Respect reduced-motion preferences. Never animate everything at once.

### 6. What to Avoid

- Generic blue-and-white SaaS design.
- Corporate enterprise dashboard aesthetics.
- Excessive glassmorphism.
- Full-screen neon effects and RGB overload.
- Green Matrix-rain hacker stereotypes.
- Pixel fonts everywhere.
- Excessive cards, gradients and glowing borders.
- Unnecessary visual noise in the coding workspace.

### Final Design Test

Someone should recognise Desiide as a modern developer product even before reading its name.

The landing page should make someone want to explore it. The IDE should make someone want to spend their working hours inside it.

**Personality outside. Focus inside.**
