# Desiide

Bring-your-own-model AI coding for VS Code, with routing and risk decisions you can see.

> **Pre-alpha.** This extension is under active development and isn't published yet. See the [project README](https://github.com/SaketMunda/desiide#readme).

- Use local models (Ollama) or your own Anthropic / OpenAI-compatible keys.
- Every edit is a reviewable diff, and every command passes a conservative policy gate.
- Routing and risk decisions (Jev) are shown with their reasons and probabilities.
- No telemetry. Keys stay in VS Code SecretStorage.
